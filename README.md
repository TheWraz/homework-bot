# Homework Bot — Telegram бот для проверки домашних работ 📚

## 📌 О проекте

Telegram-бот, который обращается к API сервиса «Практикум Домашка» и отслеживает статус домашней работы. Бот сообщает в Telegram, когда работа отправлена на ревью, проверена, принята или возвращена на доработку.

Бот также логирует свою работу и уведомляет о критических ошибках.

## 🤖 Что умеет бот

- Раз в 10 минут опрашивает API сервиса «Практикум Домашка»
- Проверяет статус домашней работы
- Отправляет уведомления в Telegram при изменении статуса:
  - работа отправлена на ревью
  - ревью пройдено, работа принята
  - работа возвращена на доработку
- Логирует свою работу (уровни DEBUG, ERROR, CRITICAL)
- Уведомляет в Telegram о критических ошибках
- Не дублирует сообщения об одной и той же ошибке

## 🛠 Технологии

- **Python** 3.12+
- **pyTelegramBotAPI** — библиотека для работы с Telegram Bot API
- **Requests** — для запросов к API Практикума
- **python-dotenv** — управление переменными окружения
- **Pytest** — тестирование
- **Flake8** — проверка кода на соответствие PEP8

## 📦 Установка и запуск

1. Клонировать репозиторий
```
git clone https://github.com/TheWraz/homework_bot
cd homework_bot
```

2. Создать и активировать виртуальное окружение
```
python -m venv venv
source venv/Scripts/activate
```

3. Установить зависимости
```
pip install -r requirements.txt
```

4. Настроить переменные окружения

Создайте файл `.env` в корне проекта:
PRACTICUM_TOKEN=ваш_токен_практикума
TELEGRAM_TOKEN=ваш_токен_бота
TELEGRAM_CHAT_ID=ваш_chat_id

5. Запустить бота
```
python homework.py
```
